## Backfill decision

- Mark the 103 explicit fixture/regression drugs and runs 749/750 with
  `test:legacy-shared-schema`.
- Mark the 10 real drugs, all PBS items, and the 18 historical ingestion runs
  as `production`.
- Create one explicit production-scoped ingestion authority root with ID `-1`
  and mode `legacy_backfill`.
- Assign all historical predictions and schedule changes to that root because
  their original run lineage cannot be reconstructed honestly.

The SQL migration aborts unless these counts and dependency assumptions still
hold. It does not delete any row.
